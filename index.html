System Architecture & Technology Stack

            

              

                
Frontend Layer

                
Next.js 14 (App Router) + React + Tailwind CSS

                
Role-based dashboard views, S3 presigned sheet uploaders, real-time WebSocket queue telemetry.

              

              

                
Backend Middleware

                
Node.js + NestJS Modular Architecture

                
Dedicated Webhook Guards for Meta HMAC, Google Ads tokens, LinkedIn OAuth2, and Apollo REST hooks.

              

              

                
Master Warehouse DB

                
PostgreSQL 16 + Prisma ORM

                
Unique composite index on (normalized_phone, project_id) enforcing sub-millisecond duplicate detection.

              

              

                
Queue & Cloud Storage

                
Redis + BullMQ + AWS S3

                
Instant jobs for Real-Time mode (1–5s SLA); repeatable Cron workers for 1m/5m/15m/30m/1h/Daily batches.
